# StateTune 论文深度讲解

> **StateTune: Transforming LLM-Assisted EDA Flow Tuning into a Stateful, Closed-Loop Process**
> KunLong Li, Shangshang Yao, Su Zheng, Lingli Wang；arXiv:2608.23601
> 原文：[2608.23601_StateTune.pdf](./2608.23601_StateTune.pdf) · [2608.23601_StateTune.txt](./2608.23601_StateTune.txt)

## 1. 一句话定位

**StateTune 把 LLM 辅助 EDA flow tuning 从“外部 proposer + 临时上下文”改成 stateful closed-loop：用 typed、evidence-gated 的 persistent optimization memory 同时驱动候选生成和 EHVI-guided、runtime-aware budget allocation，在 Cadence 工业流程的 2 工艺 × 3 设计矩阵上取得最强 hypervolume。**

## 3. 输入 / 输出

### 3.1 输入

- Cadence Genus/Innovus 工业 flow。
- ASAP7 和 NanGate45 两个工艺节点。
- JPEG、AES、IBEX 三类 benchmark。
- 参数空间、多目标指标和 quick-stage/full-flow 评估成本。

```text
statetune_input = {
  technology: ["ASAP7","NanGate45"],
  designs: ["JPEG","AES","IBEX"],
  objectives: ["hypervolume","WNS","area","power"],
  full_flow_cost_hours: 4
}
```

### 3.2 输出

- 持久优化记忆 $M_t$，包含规则、敏感性和失败模式。
- 下一轮候选配置和 quick-stage promotion 排序。
- 最终 Pareto frontier、hypervolume、WNS、area、power。

```text
statetune_output = {
  best_hypervolume: "strongest on all six blocks",
  memory_ablation_hv_loss: "58.5%",
  gating_ablation_hv_loss: "43.4%",
  reproducibility: "CV<7% on five of six blocks"
}
```

## 4. 方法 / 架构 / 构建

```text
Evaluation results
        |
Evidence-gated persistent memory M_t
        |
   +----+---------------------+
   |                          |
Candidate generation      Budget allocation
   |                          |
LLM proposal              EHVI + runtime-aware promotion
   |                          |
Quick-stage / full-flow evaluation
```

StateTune 的关键不是把 LLM 当 smarter proposer，而是把 tuning 状态显式化。每次 evaluation 都更新 memory，memory 同时服务 proposal 和 promotion，避免规则污染，并把昂贵 full-flow 预算给 quick-stage 中预期 Pareto 收益最高的候选。

## 5. 关键公式

- 优化器状态：$M_t=Update(M_{t-1},x_t,y_t,g_t)$，其中 $g_t$ 是 evidence gate。
- Candidate generation：$x_{t+1}\sim \pi_{LLM}(\cdot\mid M_t)$。
- EHVI 增益：$EHVI(x)=E_{f(x)}[\max(0, HV(Pareto\cup\{f(x)\})-HV(Pareto))]$。
- Runtime-aware promotion：$rank(x)=\frac{EHVI(x)}{cost(x)}$。
- 记忆污染风险通过 evidence gating 控制，移除 gating 会使 HV 下降 43.4%。

## 6. 训练 / 实验 / 评测协议

- LLM 不训练，使用 closed-loop inference。
- 六个 benchmark blocks：2 个技术节点 × 3 个设计。
- baseline：qEHVI、Optuna-TPE、Random、RankTuner、CROP。
- 指标：final hypervolume、WNS、area、power。
- 消融：persistent memory、evidence gating、memory poisoning、cross-design transfer、three-seed reproducibility。

## 7. 创新点

1. 将 LLM 辅助 EDA tuning 重构为 stateful closed-loop，而非 transient proposer。
2. 提出 typed、evidence-gated persistent optimization memory，同时驱动候选生成和 budget allocation。
3. 引入 EHVI-guided、runtime-aware promotion，把 quick-stage 结果与 full-flow 成本统一。

## 9. 与芯片流程的关系

StateTune 是跨综合、floorplan、placement、CTS、routing 的 flow tuning 框架，评估基于 Cadence 工业流程和 signoff 级 WNS/area/power。它不替换 EDA 工具，而是把工具反馈转化为可复用的调参记忆，改善后续候选和预算决策。

## 10. 讨论与局限

- 实验使用 Cadence 工业流程，开源复现受工具许可和 PDK 限制。
- 六个 block 的矩阵规模有限，跨设计 transfer 虽有分析但仍需更大工业设计验证。
- persistent memory 对规则质量和证据门控敏感，错误规则会显著伤害 hypervolume。
- EHVI 依赖代理模型，quick-stage 与 full-flow 不一致时 promotion 可能错配。

## 12. 一分钟复述

LLM 调 EDA 参数时，如果每次只给一段临时上下文，学到的规则用完就丢。StateTune 建立一个持久 memory，把失败原因、参数交互和敏感性都存下来；LLM 用 memory 生成候选，EHVI 再按“每单位 runtime 能带来多少 Pareto 前沿提升”分配预算。这样 tuning 不只是生成配置，而是一个会积累经验的状态化闭环。
