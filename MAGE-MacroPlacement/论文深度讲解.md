# MAGE Macro Placement 论文深度讲解

> **MAGE: Human-Like Macro Placement via Agentic Multimodal Reasoning**
> Andrew B. Kahng, Sayak Kundu, Bodhisatta Pramanik
> arXiv:2607.18536
> 原文：[2607.18536_MAGE-MacroPlacement.pdf](./2607.18536_MAGE-MacroPlacement.pdf) · [2607.18536_MAGE-MacroPlacement.txt](./2607.18536_MAGE-MacroPlacement.txt)

## 1. 一句话定位

**MAGE 用十个专业 agent 和六阶段流程编码专家 floorplanning 规则，并用 Go-With-The-Winners 锦标赛式演化在保持结构规整性的同时优化 WNS/TNS；相对 Hier-RTLMP 提高 47.0% WNS 和 80.4% TNS。**

这句话里的三个承重点：

1. **结构优先再优化 PPA** — 第一阶段生成符合层次、分组、对齐和通道规则的 placement，第二阶段用 GWTW 演化实现 timing 指标。
2. **四个 human-likeness 指标** — notch、whitespace、pocket、alignment 量化传统 PPA 没有直接捕捉的专家审美。
3. **视觉反馈** — 视觉审计和验证准则让多模态 agent 能发现 fragmentation、通道狭窄和 pin access 问题。

## 3. 输入 / 输出

### 3.1 输入

- 设计网表 $N$、floorplan 规格 $F$、配置 $\Theta$。
- 宏集合 $M$、标准单元区域 $S$、core 区域 $C$、IO/pin 信息 $I$。
- 知识库 $K$：自然语言 floorplanning 指令、验证准则和视觉检查规则。

```text
design_input = {
  netlist: "nangate45/ariane",
  floorplan: "rectilinear_variant_2",
  macros: 42,
  knowledge: ["group_by_hierarchy","avoid_pockets","align_boundaries"]
}
```

### 3.2 中间产物

- 宏分组 $G=\{g_1,\dots,g_k\}$。
- 参考组 $g_{ref}$ 和参考 placement。
- 几何变换 $T_g$。
- 候选 placement 的 post-route wirelength 和 timing。

```text
group_plan = {
  g1: [m0,m2,m5],
  g2: [m1,m4,m7],
  reference_group: "g1"
}
```

### 3.3 输出

```text
selected_placement = {
  rwl_mm: 25766,
  power_mW: 4466,
  WNS_ps: -126,
  TNS_ns: -310.8,
  SHM: 0.70
}
```

## 4. 方法与架构

### 4.1 整体 Pipeline

```text
Inputs(N,F,I) + Knowledge Corpus(K)
           │
           ▼
Design Interpretation
           │
           ▼
Macro Grouping
           │
           ▼
Spatial Organization / Reference Placement
           │
           ▼
Feasibility Validation + Visual Check
           │
           ▼
GWTW Tournament Refinement
           │
           ▼
Visual Audit + Final Selection
```

### 4.2 核心模块逐个详解

- **设计解读**：从网表和 floorplan spec 提取宏类型、层次、pin access 和 core 几何。
- **宏分组**：按 hierarchy、dataflow、功能相似性和对齐机会分组。
- **空间组织**：先为参考组生成 placement，再通过几何变换扩展到其他组。
- **合法性/视觉检查**：检查 legality、pin access、keepouts、whitespace 质量和边界占用。
- **GWTW refinement**：多个候选 placement 锦标赛竞争，高质量候选把反馈传播给下一轮。

### 4.3 模块职责矩阵

| 模块 | 输入 | 输出 | 工具/模型 | 是否需训练 |
|---|---|---|---|---|
| Design Interpretation | netlist, spec | macro metadata | LLM agent | 否 |
| Macro Grouping | metadata | groups | LLM agent | 否 |
| Spatial Organization | groups | candidate placement | LLM agent | 否 |
| Visual Audit | placement images | violations, suggestions | VLM | 否 |
| GWTW Refinement | candidates | refined placement | evaluator + LLM | 否 |

## 5. 关键公式

### 5.1 总体 human-likeness score

$$
S_{HM}=\frac{1}{4}\left(S_{notch}+S_{ws}+S_{pocket}+S_{align}\right)
$$

- $S_{HM}$：总体 human-likeness score
- $S_{notch}$：notch score
- $S_{ws}$：whitespace score
- $S_{pocket}$：pocket score
- $S_{align}$：alignment score

### 5.2 Notch score

$$
S_{notch}=\max\left(0,1-\frac{\sum_i d_i l_i}{L_{total}\cdot 2c_w}\right)
$$

- $d_i$：第 i 个 notch 的垂直深度
- $l_i$：notch 持续长度
- $L_{total}$：扫描轮廓总长
- $c_w$：最小通道宽度

### 5.3 Alignment score

$$
S_{align}=w_1 S_{snap}+w_2 S_{edge}+w_3 S_{corner}+w_4 S_{stack}
$$

- $S_{snap}$：边界吸附得分
- $S_{edge}$：边对齐得分
- $S_{corner}$：角点占位得分
- $S_{stack}$：宏堆叠得分
- $w_1,w_2,w_3,w_4$：论文权重为 $0.3,0.2,0.2,0.3$

## 6. 训练与实验设置

### 6.1 是否需要训练

不训练。专家知识通过 prompt、agent 交互、视觉检查和 refinement 标准注入。

### 6.2 实验设置

- NanGate45 与 GlobalFoundries 12nm enablements。
- baseline：human expert、两个商业 macro placer release、OpenROAD Hier-RTLMP。
- 指标：post-route rWL、power、WNS、TNS、SHM。

### 6.3 关键实验结果

| 对比 | WNS 改善 | TNS 改善 |
|---|---:|---:|
| vs Hier-RTLMP | 47.0% | 80.4% |
| vs human expert | 18.3% | 72.5% |
| vs commercial baselines | 11.1%–19.3% | 70.0%–74.0% |

MAGE 在 timing 上显著优于 baseline，rWL 和 power 基本可比；human-likeness 指标也更高。

## 7. 创新点

1. 第一个以 human-like macro placement 为明确目标的 agentic multimodal 框架。
2. 提出 notch、whitespace、pocket、alignment 四个可计算结构指标。
3. 用结构优先生成 + GWTW 演化的两阶段策略平衡 human-likeness 和 PPA。

## 9. 与芯片流程的关系

### 9.1 在全流程中的位置

MAGE 位于 floorplan/macro placement refinement。它接手网表和 floorplan spec，输出宏布局，为后续标准单元 placement 和 routing 提供更规整的宏通道和 whitespace。

### 9.2 从“human-like placement”到“能做成芯片”之间还缺什么

论文报告 post-route rWL、power、WNS/TNS，但未覆盖 DRC/LVS、IR drop、多 corner 签核和实际制造反馈。

## 10. 讨论与局限

### 10.1 论文自述的局限

人味指标与 PPA 并非完全单调，某些 case 会牺牲 rWL 换取 timing。

### 10.2 代码/复现层面的问题

未提供公开代码；商业 placer baseline 匿名，难以完全复现。论文给出指标定义和六阶段框架，但 agent prompt、知识库原文和视觉审计实现没有随文公开。

### 10.3 本资料包的批判性分析

视觉审计是核心依赖，移除视觉反馈后 WNS/TNS 显著下降。结构指标的定义依赖固定通道宽度和 tolerance，跨工艺时可能需要重标定。

## 12. 一分钟复述版

专家宏布局不仅看 HPWL，还看分组、对齐、通道和 pocket。MAGE 用十个 agent 分六阶段生成宏布局，先满足结构规则，再用 GWTW 锦标赛筛选更优 timing 候选。它定义 notch、whitespace、pocket、alignment 四个指标，量化“像人做的布局”；实验表明相比 Hier-RTLMP 显著改善 WNS/TNS。
