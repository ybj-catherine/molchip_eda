# MAGE Macro Placement 论文深度讲解

> **MAGE: Human-Like Macro Placement via Agentic Multimodal Reasoning**
> Andrew B. Kahng, Sayak Kundu, Bodhisatta Pramanik；arXiv:2607.18536
> 原文：[2607.18536_MAGE-MacroPlacement.pdf](./2607.18536_MAGE-MacroPlacement.pdf) · [2607.18536_MAGE-MacroPlacement.txt](./2607.18536_MAGE-MacroPlacement.txt)

## 1. 一句话定位

**MAGE 用十个专业 agent、六阶段流程和视觉审计把专家 floorplanning 知识编码为可验证的自然语言规则，并以 GWTW 锦标赛式演化在保持结构规整性的同时优化 WNS/TNS；相对商业宏布局器和 Hier-RTLMP 均取得显著 timing 改进。**

## 3. 输入 / 输出

### 3.1 输入

- 设计网表 $N$、floorplan 规格 $F$、配置 $\Theta$。
- 宏集合 $M$，尺寸/朝向/IO/pin 信息，标准单元区域 $S$、core region $C$。
- 专家知识库 $K$，包含自然语言 floorplanning 指令、验证准则和视觉检查规则。

```text
design_input = {
  netlist: "nangate45/ariane",
  floorplan_spec: "rectilinear_core_variant_2",
  macros: 42,
  macro_groups: 7,
  knowledge_corpus: ["group_by_hierarchy", "avoid_pockets", "align_boundaries"]
}
```

### 3.2 输出

- 初始宏布局 $X^0$ 与 refined placement $X^*$。
- 宏分组 $G$、参考组 $g_{ref}$ 和几何变换 $T_g$。
- post-route PPA：rWL、power、WNS、TNS。
- 人味指标：$S_{notch},S_{ws},S_{pocket},S_{align},S_{HM}$。

```text
selected_placement: {
  rwl_mm: 25766,
  power_mW: 4466,
  WNS_ps: -126,
  TNS_ns: -310.8,
  SHM: 0.70
}
```

## 4. 方法 / 架构 / 构建

```text
Inputs(N,F,I) + Knowledge Corpus(K)
             |
Phase 1  Design Interpretation
Phase 2  Macro Grouping
Phase 3  Spatial Organization / Reference Placement
Phase 4  Feasibility Validation + Visual Check
Phase 5  Refinement / Tournament GWTW
Phase 6  Visual Audit + Final Selection
             |
        Human-like macro placement
```

十个专业 agent 分工处理设计解读、宏分组、空间组织、合法性检查、细化、视觉审计和候选传播。第一阶段优先结构规则，第二阶段用 Go-With-The-Winners 保留高质量 variant，把 wirelength/timing 反馈传播给后续候选。

## 5. 关键公式

- 总体人味分数：$S_{HM}=\frac{1}{4}(S_{notch}+S_{ws}+S_{pocket}+S_{align})$。
- Notch score：$S_{notch}=\max(0,1-\frac{\sum_i d_i l_i}{L_{total}\cdot 2c_w})$，其中 $d_i$ 是凹口深度，$l_i$ 是持续长度，$c_w$ 是通道宽度。
- Pocket score：$S_{pocket}=1-\frac{A_{pocket}}{A_{free}}$。
- Alignment score：$S_{align}=w_1 S_{snap}+w_2 S_{edge}+w_3 S_{corner}+w_4 S_{stack}$，权重为 $0.3,0.2,0.2,0.3$。
- 合法约束：宏必须位于 core 内，且任意两个宏不产生正面积重叠。

## 6. 训练 / 实验 / 评测协议

- 不训练或微调模型，知识通过 prompt、agent 交互、视觉检查和 refinement 标准注入。
- 在 NanGate45 与 GlobalFoundries 12nm enablements 上评测，覆盖标准、rectilinear、高利用率和 unseen designs。
- baseline 包括 human expert、两个商业 macro placer release、OpenROAD Hier-RTLMP。
- 主要指标：post-route rWL、power、WNS、TNS；人味指标与消融实验。

## 7. 创新点

1. 第一个明确以 human-like macro placement 为目标的 agentic multimodal 框架。
2. 用 notch、whitespace、pocket、alignment 四个结构指标量化“专家式 floorplan”。
3. 两阶段合成：先结构优先生成，再 GWTW 演化优化 PPA，同时保持结构特征。

| MAGE | Macro Placement Agentic Engine |

| TNS | Total Negative Slack |
| rWL | Routed Wirelength |
| SHM | Overall human-likeness score |

## 9. 与芯片流程的关系

MAGE 处于 floorplan/macro placement refinement 阶段。它不替代综合、CTS 或 router，而是把专家在 floorplan 阶段关心的层次、数据流、对齐、可布线性、电源网格约束显式化，为后续 standard-cell placement 和 routing 留下更干净的结构空间。

## 10. 讨论与局限

- 人味指标与最终 PPA 之间的相关性有趋势，但不是单调保证；有些 case 会以更高 rWL 换取更优 TNS。
- 工业流程比较受匿名商业工具版本和工艺 enablement 影响，不能直接等同所有商业流程。
- 视觉审计依赖 VLM，视觉反馈失败会显著损害 WNS/TNS 和 SHM。
- 当前框架聚焦宏布局 refinement，未覆盖完整 RTL-to-GDS 自动闭环。

## 12. 一分钟复述

专家做宏布图时不只是看 HPWL，还看分组、边界对齐、通道和 pocket。MAGE 把这些原则写成十 agent 的六阶段流程，先用结构规则生成候选，再用视觉审计过滤，最后通过锦标赛演化保留高 TNS/WNS 且高结构分的 placement。它的关键是“先保证人味结构，再优化 PPA”。
