# CHIP-MAP 论文深度讲解

> **CHIP-MAP: A Collaborative Optimization Framework for Macro Placement Using Large Language Models**
> Yiming Du, RenYe Yan, Yunfan Yang, Frank Qu, Jiajun Tan, ZhiYu Zheng, Yiming Gan, Ling Liang, Zongwei Wang, YiMao Cai；DATE 2026
> DOI：10.23919/DATE69613.2026.11539734

## 1. 一句话定位

**CHIP-MAP 用多 agent 协作和反馈驱动优化替代直接生成最终宏布局，并通过 Module Link Weight Analyzer 与 Standard Cell Usability Score 两个工具引导细粒度布局精化；在 5 个 130nm/45nm benchmark 上最高降低 1.5% 面积并平均修复 61.6% TNS。**

## 3. 输入 / 输出

### 3.1 输入

- 宏模块网表、模块连接关系、宏属性。
- 工艺节点信息，覆盖 130nm 与 45nm。
- 设计类型从低功耗 core 到多核处理器。

```text
chipmap_input = {
  netlist: "macros_and_standard_cells",
  modules: ["cpu_core","memory","bus","accelerator"],
  links: [[module_a,module_b,weight], ...],
  process_node: "45nm"
}
```

### 3.2 输出

- 多 agent 精化后的宏布局和模块相对位置。
- 模块连接权重、标准单元可用性评分。
- 面积、wirelength、TNS、timing 等反馈指标。

```text
chipmap_output = {
  area_reduction: "up to 1.5%",
  average_tns_repair: "61.6%",
  wirelength_reduction: "reported",
  timing_improvement: "reported"
}
```

## 4. 方法 / 架构 / 构建

```text
Netlist + macro properties + constraints
          |
LLM multi-agent collaboration
          |
Module Link Weight Analyzer (MWA)
          |
Standard Cell Usability Score (SCUS)
          |
Feedback-driven layout refinement
          |
Final macro placement
```

CHIP-MAP 不依赖大训练数据或中间 PPA 代理作唯一目标。它把 LLM 的语义生成能力用于布局规则理解和迭代优化；两个工具分别补充模块级连接结构和标准单元可用空间信息，使 agent 的修改更有依据。

## 5. 关键公式

- 模块连接权重：$w_{ij}=g(|nets(i,j)|, dataflow_{ij}, hierarchy_{ij})$，用于 MWA 排序相邻模块的重要性。
- 标准单元可用性：$SCUS(R)=h(free\_area_R, routing\_pressure_R, macro\_boundary_R)$，分数高表示该区域更适合标准单元。
- 布局质量反馈：$Q=Q(area, wirelength, TNS, timing)$，agent 根据反馈更新宏位置和模块分组。
- 细粒度精化目标：$\min Q(X)$，同时保持 legality 和 macro non-overlap。

## 6. 训练 / 实验 / 评测协议

- LLM 不训练，采用多 agent 推理与工具反馈。
- 在 5 个 benchmark 上评测，覆盖 130nm 和 45nm 工艺节点。
- 对比传统模拟退火、解析优化和强化学习宏布局方法的局限，重点验证面积、TNS、wirelength 和 timing。

## 7. 创新点

1. 将 macro placement 形式化为多 agent 协作与反馈驱动优化。
2. 引入 Module Link Weight Analyzer，显式建模模块连接结构。
3. 引入 Standard Cell Usability Score，把标准单元可用空间纳入宏布局精化。

## 9. 与芯片流程的关系

CHIP-MAP 作用于 floorplan/macro placement 阶段，但通过 TNS、wirelength 和标准单元可用性反馈延伸到 placement/routing 质量。它适合作为物理设计前端的多 agent 布局优化层，在标准单元布局之前确定宏的相对位置与区域可用性。

## 10. 讨论与局限

- 当前公开可验证信息主要来自摘要和 Crossref/OpenAlex 元数据，缺少公式、算法伪代码和完整表格。
- benchmark 数量为 5 个，规模覆盖有限。
- 未说明 LLM backend、agent 数量、迭代预算和工具调用失败处理。
- 面积和 TNS 改善需要更完整的 PPA 表格和统计显著性才能评估鲁棒性。

## 12. 一分钟复述

CHIP-MAP 用 LLM 多 agent 协作优化宏布局，不把 LLM 当作一次性布局生成器，而是持续根据 MWA 和 SCUS 反馈调整模块位置。MWA 看模块间连接强弱，SCUS 看标准单元可用空间质量，最终改善面积、wirelength、TNS 和 timing。
