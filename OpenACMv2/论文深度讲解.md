## 1. 一句话定位

**OpenACMv2 把 Approximate Digital Compute-in-Memory（DCiM）设计从“分别做近似乘法器搜索和晶体管 sizing”改成 Accuracy-Constrained Co-Optimization（ACCO）的两级优化**：Level-1 用 PEA-GNN 图神经网络替代昂贵 EDA 评估，在 $8^9$ 个近似 compressor 配置与 SRAM macro 参数空间中找 MRED/NMED 约束下的 PDP Pareto 解；Level-2 对选中的标准单元与 6T SRAM bitcell 做 PVT/variation-aware 晶体管 sizing。实验显示 Level-1 架构搜索已经带来约 50%+ PDP 下降，Level-2 再提供个位数百分比 PDP 改善且不改变 accuracy；PEA-GNN 相对 OpenROAD/OpenSTA/VCS 评测在 8-bit 快 142×、16-bit 快 464×。

这句话里的四个承重点：

1. **ACCO 把应用精度预算提升为一级约束** — 不是先“最大化近似”再后验看误差，而是在 Level-1 搜索时就把 MRED/NMED 约束写成硬约束。
2. **架构层和晶体管层解耦但仍串成同一 flow** — Level-1 探索 compressor 组合、PP 列近似与 SRAM 宏参数；Level-2 只对短名单做 sizing，从而避免高维联合优化的收敛差。
3. **PEA-GNN 是支撑 ACCO 的快速 surrogate** — 它把 approximate multiplier 压缩树建模为 stage-wise graph，预测 MRED/NMED/delay/area/power，而不是每个 candidate 都跑综合+仿真。
4. **兼容 FreePDK45/OpenROAD** — 结果不是只存在于理想模型，而是可被标准数字设计工具链重复评估，降低落地门槛。

## 3. 输入 / 输出

### 3.1 输入

Level-1 的 approximate multiplier 配置用数组 $a$ 表示，长度等于可配置 compressor 位置数 $t=9$，每个位置选 compressor type index 0 到 7：

```text
{
  "width": 8,
  "exact_high_columns": [8, 9, ..., 15],
  "approx_columns": [0, 1, ..., 7],
  "compressor_slots": [2, 5, 0, 3, 1, 7, 4, 6, 3],
  "sram_capacity_bits": 8192,
  "sram_rows": 256,
  "sram_cols": 32,
  "mux_ratio": 4,
  "array_count": 2
}
```

### 3.2 中间产物

OpenACMv2 生成可综合的 8-bit/16-bit approximate multiplier 电路与 SRAM macro 网表，例如 compressor reduction tree 的三个阶段：

```text
Stage 1: partial-product generation
Stage 2: configurable reduction tree with exact/approximate 4-2 compressors
Stage 3: final carry-propagate adder
```

对每个配置，PEA-GNN 输出预测指标；对最终短名单，再生成门级/晶体管级候选并交给 SPICE/OpenROAD 评估。

### 3.3 输出

输出是 accuracy-PDP Pareto 解和两级优化报告：

```text
selected_architecture:
  multiplier_width: 8
  compressor_slots: [...]
  mred: 1.47e-2
  nmred: ...
  pdp_level1: 204 fJ
  pdp_level2: 199 fJ
  psnr_test0: 51.03 dB
  psnr_test1: 51.38 dB
```

## 4. 方法与架构

### 4.1 整体 Pipeline

```text
  Application accuracy budgets
  (MRED or NMED)
        │
        ▼
  Level-1: Architecture Search
  ┌──────────────────────────────────────────┐
  │ multiplier: compressor assignment a      │
  │            PP-column approximation       │
  │ SRAM: row/col split, array count, mux    │
  │ surrogate: PEA-GNN fast PPA + error      │
  │ optimizer: CBO/PSO/SA/MOEA-D/NSGA-II     │
  └────────────────────┬─────────────────────┘
                       ▼
  Selected shortlist (architecture candidates)
        │
        ▼
  Level-2: PVT/variation-aware transistor sizing
  ┌──────────────────────────────────────────┐
  │ standard cells: width-sharing groups     │
  │ SRAM: 6T bitcell sizing                  │
  │ evaluation: SPICE Monte Carlo over PVT   │
  │ optimizer: single/multi-objective        │
  └────────────────────┬─────────────────────┘
                       ▼
  Final DCiM PE / SRAM macro candidates
```

### 4.2 核心模块逐个详解

#### 模块 1：Approximate Multiplier Architecture Encoder

论文限制 $N$-bit multiplier 只在低 $N$ 个 PP 列做近似，高列保持 exact。可配置位置 $t=9$，每个位置可选 compressor type index 0–7，因此架构搜索空间为 $8^9$。

#### 模块 2：PEA-GNN Surrogate

PEA-GNN 把 compressor assignment 编码为按 reduction stage 分层的有向图：节点是 HA/FA/exact or approximate 4-2 compressor，边是信号互连。节点特征把输入位概率与误差向量 fused 成 `p_in * e`；GraphSAGE 在 stage subgraph 内消息传递，最后把 critical nodes 拼成全局表示，用 shared MLP 预测 MRED/NMED/delay/area/power。

#### 模块 3：Level-2 Sizing

晶体管宽度按等效器件分组以降低维度，并用 SPICE 蒙特卡洛跨 PVT corner 检查逻辑正确性。对 standard cell，宽度 bounds 和 corner 最差值决定 PDP/area；对 SRAM 6T bitcell，则用 hold/read/write SNM、读写 delay 与 power 的 worst-case aggregate。

### 4.3 模块职责矩阵

| 模块 | 输入 | 输出 | 用到的模型/工具 | 是否需训练 |
|---|---|---|---|---|
| Architecture config generator | width、budget | compressor/slot/SRAM config | OpenACM circuit generator | 否 |
| PEA-GNN | config graph | MRED/NMED/PPA 预测 | GNN + MLP head | 是 |
| Level-1 optimizer | surrogate | accuracy-PDP Pareto set | MOEA/D、NSGA-II、PSO、SA、CBO | 否 |
| Level-2 standard cell sizing | shortlisted cells | optimized transistor widths | SPICE Monte Carlo | 否 |
| SRAM top/bottom search | capacity budget | bank config + bitcell sizes | OpenYield、SPICE | 否 |

## 5. 关键公式

### 5.1 MRED

$$
\mathrm{MRED}(a)=\frac{1}{|U^{+}|}\sum_{(x,y)\in U^{+}}
\frac{\mathrm{ED}_a(x,y)}{R_{\mathrm{exact}}(x,y)}
$$

- $a$：approximate multiplier 配置。
- $U^{+}$：满足 $R_{\mathrm{exact}}(x,y)>0$ 的输入子集。
- $\mathrm{ED}_a(x,y)$：配置 $a$ 的绝对算术误差。
- $R_{\mathrm{exact}}(x,y)$：精确乘法结果。

### 5.2 NMED

$$
\mathrm{NMED}(a)=\frac{1}{|U|}\sum_{(x,y)\in U}
\frac{\mathrm{ED}_a(x,y)}{R_{\max}}
$$

- $U$：用于评估的输入集合。
- $R_{\max}=(2^N-1)^2$：最大精确乘法结果。
- $\mathrm{NMED}\in[0,1]$，提供绝对误差尺度。

### 5.3 Top-Level Accuracy-Constrained Objective

$$
\min_{a\in\{0,\dots,K-1\}^t}\left(\mathrm{MRED}(a),\, \mathrm{PDP}(a)\right)
\quad \text{s.t.}\quad \mathrm{NMED}(a)\le \varepsilon_{\mathrm{NMED}}
$$

- $K=8$：compressor type 数量。
- $t=9$：可配置 compressor 位置数量。
- $\mathrm{PDP}(a)$：power-delay product。
- $\varepsilon_{\mathrm{NMED}}$：应用级 NMED 精度预算。

### 5.4 PEA-GNN 输入概率权重与节点特征

$$
\omega_i=\prod_{j=1}^{n} p_j^{b_{i,j}}(1-p_j)^{1-b_{i,j}},
\qquad b_i\in\{0,1\}^n
$$

$$
\boldsymbol{h}_v=\boldsymbol{p}^{\mathrm{in}}\odot \boldsymbol{e}^{(y)}
$$

- $\omega_i$：输入组合 $b_i$ 的概率权重。
- $p_j$：第 $j$ bit 为 1 的边际概率。
- $\boldsymbol{p}^{\mathrm{in}}$：由输入概率向量导出的节点输入概率向量。
- $\boldsymbol{e}^{(y)}$：compressor variant 的 bit-level error vector。
- $\odot$：逐元素乘。

### 5.5 Stage-Wise Message Passing

$$
\boldsymbol{h}_v^{(k+1)}=\sigma\left(W_k\left[\boldsymbol{h}_v^{(k)} \parallel
\mathrm{AGG}_k\left(\left\{\boldsymbol{h}_u^{(k)}:u\in N(v)\right\}\right)\right]\right)
$$

- $\sigma$：非线性激活。
- $W_k$：第 $k$ 层可学习权重。
- $\parallel$：向量拼接。
- $\mathrm{AGG}_k$：邻居聚合器。
- $N(v)$：节点 $v$ 在图中的邻居。

### 5.6 Bottom-Level Functional Correctness

$$
c\left(V_{\mathrm{out}}(w;b_i)\right)=H_{i,:}^{(y)}
\quad \forall i\in\{1,\dots,2^n\}
$$

$$
\min_{w\in W_y}\left(\mathrm{PDP}(w),\,A(w)\right)
\quad \text{s.t.}\quad w_k\in[w_k^{\min},w_k^{\max}]
$$

- $w$：sizing 设计变量。
- $V_{\mathrm{out}}(w;b_i)$：SPICE 仿真的输出电压。
- $H^{(y)}$：目标 truth table。
- $A(w)$：cell area。
- $w_k^{\min},w_k^{\max}$：第 $k$ 个尺寸变量边界。

### 5.7 SRAM FOM

$$
D_{\max}=\max\{D_{\mathrm{rd}},D_{\mathrm{wr}}\},\quad
P_{\max}=\max\{P_{\mathrm{rd}},P_{\mathrm{wr}}\}
$$

$$
\mathrm{FOM}(r,c,\mu,n_a)=-\log_{10}\left(P_{\max}A_{\mathrm{bank}}D_{\max}\right)
$$

- $D_{\mathrm{rd}},D_{\mathrm{wr}}$：读/写访问延迟。
- $P_{\mathrm{rd}},P_{\mathrm{wr}}$：读/写动态功耗。
- $A_{\mathrm{bank}}$：bank 面积估计。
- $r,c,\mu,n_a$：行数、列数、mux ratio、array count。

## 6. 训练与实验设置

### 6.1 是否需要训练

PEA-GNN 需要训练。实现用 PyTorch 与 PyTorch Geometric（PyG），优化器为 Adam。训练数据由 OpenACMv2 自动生成：基于 Nangate45 nm open-cell library 合成 8/16-bit approximate multiplier，并用 OpenROAD/OpenSTA/VCS 在 5 ns clock、10 fF output load 下做 EDA ground truth。

### 6.2 实验设置

- 硬件：Intel Xeon Gold 6330（2.00 GHz）+ NVIDIA A100 40 GB。
- 流程兼容 FreePDK45 与 OpenROAD。
- Level-1 优化器包括 CBO、PSO、SA、MOEA/D、NSGA-II。
- Level-2 用 SPICE 蒙特卡洛与 OpenYield 的 PVT-aware worst-case aggregate。
- 应用评测：8-bit 用 Cameraman+Boat/Lake 图像 blending 的 PSNR；16-bit 用 CIFAR-10 Top-1/Top-5。

- Level-1 架构搜索达到约 50%+ PDP reduction，Level-2 sizing 只提供进一步个位数百分比 PDP improvement。

- SRAM macro 的架构级配置主导 PPA，bitcell sizing 仅提供有限 headroom，外围电路限制了安全 sizing window。

## 7. 创新点

### 创新点 1：把 accuracy constraint 显式放进 DCiM 联合优化

OpenACMv2 用 ACCO 把应用级 MRED/NMED 约束与架构/晶体管参数统一起来，而不是分别优化误差和 PPA 再事后挑选。

### 创新点 2：两级 decoupling 让经典优化器可扩展到大空间

8-bit/16-bit multiplier 的 compressor 组合与晶体管 sizing 联合搜索是非凸、高维问题；先架构后 sizing 的 top-down split 使 CBO/PSO/SA/MOEA/D 等经典算法获得稳定收敛。

### 创新点 3：面向压缩树的 PEA-GNN

PEA-GNN 以 reduction stage 为图结构，并把输入位概率和 compressor error 融入节点特征；相比全 EDA 内循环，16-bit 查询约快 464×，精度足以支持 accuracy-PDP Pareto 排序。

## 9. 与芯片流程的关系

### 9.1 在全流程中的位置

OpenACMv2 面向近似 DCiM/神经计算宏的架构设计。它在逻辑综合与 PPA 评估阶段决定 multiplier/SRAM macro 的结构和 transistor size，随后可交给标准数字后端继续 placement/routing。对目标而言，它比“全芯片流程”更接近模拟/定制电路与数字综合交界。

### 9.2 从“PDP Pareto 优”到“能做成芯片”之间隔着什么

论文明确未完整集成 P&R、寄生提取、IR drop、crosstalk、泄漏、throughput 与 routing congestion。PEA-GNN 预测和 OpenROAD 评估都依赖特定 cell library/load/clock 假设；Level-2 的 SPICE robustness 也不等于量产良率签核。

## 10. 讨论与局限

### 10.1 论文自述局限

- surrogate fidelity 与跨 PVT corner 的覆盖仍有风险。
- objective scope 窄，只关注 PDP 与 accuracy，遗漏 throughput、leakage、IR drop、routing congestion。
- 后端 signoff 集成不完整。
- SRAM macro/bitcell/periphery 的联合优化深度有限。

### 10.2 代码/复现层面问题

- 复现需要 OpenROAD、OpenSTA、VCS、SPICE 与 FreePDK45/OpenYield 等多个工具；VCS 是商业工具，可能限制完全开源复现。
- PEA-GNN 训练数据由框架自动生成，但训练集规模与 split 细节仍需从代码仓库确认。
- Table 2 的 Base 行没有 Lv2 PDP 单元格，表格中 `—` 是原 PDF 未给出数据的位置，本资料包未补数字。

### 10.3 本资料包的批判性分析

两级 ACCO 的贡献是把复杂 co-design 变成可执行的工程流程，但它的 Pareto 结果取决于 Level-1 surrogate 对架构误差/PPA 的排序保真度。若 surrogate 只对已知 compressor family 准、对新 compressor 或 corner 外推差，则所谓 accuracy-constrained optimum 会失真。论文用应用级 PSNR/Top-k 验证了“预算越紧质量越高”的方向，但没有证明该方法比真正的联合高保真优化更接近全局最优，只是证明它在可计算成本下稳定可行。

## 12. 一分钟复述版

1. Approximate DCiM 用低精度算术换取 PPA，但精度与架构/晶体管参数耦合严重。
2. OpenACMv2 提出 ACCO：把应用精度预算作为一级硬约束。
3. Level-1 在 8/16-bit multiplier 与 SRAM macro 上做架构搜索。
4. compressor slot 数为 9、每 slot 有 8 种，空间达 $8^9$。
5. PEA-GNN 用 stage-wise graph 预测 MRED/NMED/delay/area/power。
6. PEA-GNN 比 EDA 全流程快 142×（8-bit）到 464×（16-bit）。
7. Level-1 已实现约 50%+ PDP reduction。
8. Level-2 做 PVT/variation-aware transistor sizing，只再降几个百分点 PDP。
9. 精度约束从 Case1 收紧到 Case5 时，PSNR/Top-k 提高且 PDP 增加。
10. 局限是未完成 P&R 与 signoff，且 surrogate/corner 覆盖仍是关键风险。
