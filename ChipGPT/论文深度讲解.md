# ChipGPT SoC Floorplanning 论文深度讲解

> **ChipGPT: Leveraging Large Language Models for Automated and Optimized SoC Floorplanning**
> Aswini S, Anto Kumar R P, Varun CM, Seenuvasan P, Dhanalakshmi R, G Sekar；ICCSP 2026
> DOI：10.1109/ICCSP68173.2026.11539254

## 1. 一句话定位

**ChipGPT 把 SoC 网表、宏属性和设计约束编码成结构化文本 prompt，让 LLM agent 迭代提出 floorplan refinement，并用 wirelength、area、congestion 成本反馈驱动后续推理；论文报告相对模拟退火和商业 auto-placer 降低 15%–30% 总 wirelength。**

## 3. 输入 / 输出

### 3.1 输入

- SoC 网表、宏属性、设计约束。
- 标准 benchmark，如 IBM-HB+ 或 GSRC 风格 floorplan benchmark。
- LLM agent 可调用的 cost engine 接口。

```text
chipgpt_input = {
  netlist: "soc_top",
  macros: [{"name":"cpu","area":12000,"pins":240}, ...],
  constraints: {"aspect_ratio":1.2,"utilization":0.72},
  objective: ["wirelength","area","congestion"]
}
```

### 3.2 输出

- 迭代 refined floorplan。
- 每次 proposal 的 wirelength、area、congestion 成本。
- 最终人工可读、接近专家质量的 floorplan。

```text
chipgpt_output = {
  total_wirelength_reduction: "15%-30%",
  baselines: ["simulated_annealing","commercial_auto_placer"],
  runtime: "fraction_of_conventional_time"
}
```

## 4. 方法 / 架构 / 构建

```text
Netlist + macro properties + constraints
          |
Structured textual prompt
          |
LLM agent proposes floorplan refinement
          |
Cost engine evaluates wirelength / area / congestion
          |
Feedback guides subsequent reasoning
          |
Final floorplan
```

ChipGPT 将 LLM 视为 intelligent optimizer，而不是单次生成器。它依赖 LLM 的推理和序列建模能力处理多模态约束，并用成本反馈形成闭环。与传统模拟退火相比，LLM 能从自然语言和数值反馈中综合布局语义。

## 5. 关键公式

- 总成本：$Cost=w_1 WL+w_2 Area+w_3 Congestion$，权重由任务约束决定。
- Wirelength 代理：$WL=\sum_{e\in E} HPWL(e)$。
- 面积项：$Area=W\cdot H$，受宽高比和利用率约束。
- Congestion 项：$Congestion=\sum_{b} \max(0, demand_b-capacity_b)$。

## 6. 训练 / 实验 / 评测协议

- LLM 不训练，采用 prompt 和 cost feedback 的闭环推理。
- 在标准 benchmark 上与 simulated annealing 和 commercial auto-placer 比较。
- 指标：总 wirelength、面积、congestion、生成时间和人工竞争力。

## 7. 创新点

1. 将 LLM 作为 SoC floorplanning 的迭代优化 agent。
2. 结构化 prompt 编码 netlist、宏属性和约束。
3. 用 cost engine 的 wirelength/area/congestion 反馈驱动后续 refinement。

## 9. 与芯片流程的关系

ChipGPT 位于 physical design 的 floorplanning 阶段。它决定宏的相对位置和整体 die 形状，是后续 placement、CTS、routing 的前置约束。该工作的闭环反馈只覆盖 floorplan 级 wirelength/area/congestion，不是完整 P&R 闭环。

## 10. 讨论与局限

- 当前公开可验证信息以摘要和元数据为主，缺少完整算法伪代码和实验表。
- 15%–30% wirelength 改善未给出每个 benchmark 的统计细节和绝对基线值。
- 未说明 LLM backend、token 预算、失败恢复和 legality repair 机制。
- floorplan 成本反馈是代理指标，不等同于 post-route PPA。

## 12. 一分钟复述

SoC floorplanning 传统上依赖人工经验和模拟退火。ChipGPT 把设计信息变成结构化 prompt，让 LLM agent 提出布局修改，再用 wirelength、area、congestion 成本函数评价，并把结果喂回 agent。相比一次性生成，这种闭环更接近人类设计师“看结果、再改布局”的工作方式。
