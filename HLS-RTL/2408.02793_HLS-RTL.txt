                                                                            The first stage of the proposed pipeline, as shown in Fig. 1,
                                                                         consists of the prompting the LLM properly with well-crafted
                                                                         problem statements in a natural language (English in our
                                                                         case). Fig. 5 shows an example of such prompting for the
                                                                         problem fadd (a binary full adder). The system prompt is
                                                                         concatenated with an “one-shot” example and user prompt,
                                                                         and sent to the LLM for inference. The one-shot example
                                                                         helps to address ambiguity within the problem descriptions,
                                                                         particularly when there is a precise requirement for certain
                                                                         attributes in the LLM response. The pragmas introduced for
                                                                         each problem are optional. In our case, we use it to align
                                                                         the downstream Verilog generated with those generated by
                                                                         the existing pipeline of [5] for better comparison. Fig. 5
                                                                         also shows the response produced by LLM, an annotated
                                                                         HLS-compliant C++ code snippet with the provided function
