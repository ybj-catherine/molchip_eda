# OrderPlace 论文深度讲解

> **Order Matters: Unveiling the Hidden Impact of Macro Placement Sequences via Proxy-Guided LLM Evolution**
> Shibing Mo, Jing Liu, Jianchu Xu, Ruilin Wu；ICML 2026；arXiv:2606.08904
> 原文：[2606.08904_Order-Matters.pdf](./2606.08904_Order-Matters.pdf) · [2606.08904_Order-Matters.txt](./2606.08904_Order-Matters.txt)
> 代码：https://github.com/Explorermomo/OrderPlace

## 1. 一句话定位

**OrderPlace 把宏单元布图的“谁先放”从固定启发式升级为 LLM 演化的代码级排序策略，并用轻量 proxy 贪心评估降低顺序搜索成本；在 ISPD2005 上相对 WireMask-EA 和 EGPlace 分别把 HPWL 降低 34.04% 和 14.08%。**

## 3. 输入 / 输出

### 3.1 输入

- 宏单元集合 $M$、尺寸 $(w_i,h_i)$、面积 $A_i$、连接度数 $d_i$。
- 网表超边集合 $E$，每个网 $e_j\subseteq M$。
- 离散布局网格 $G$，规模 $g\times g$。
- LLM 初始排序策略池、手工 baseline 策略、proxy 评估种子。

```text
instance = {
  macros: [(w,h,degree), ...],
  nets: [[m1,m3,m7], [m2,m5], ...],
  grid_size: 512,
  seeds: [0,1,2]
}
```

### 3.2 输出

- 可执行的宏放置顺序策略，例如静态评分、连接权重、重力模型或动态物理启发式。
- 每个策略的 proxy fitness、best/worst HPWL、运行时间。
- 最终 HPWL、congestion，以及在混合尺寸任务中与 DREAMPlace 组合的 PPA。

```text
selected_strategy: Strategy1 (gravity entropy)
proxy_fitness: 5.68
final_hpwl: 5.68e5
vs_wiremask_ea: -34.04%
vs_egplace: -14.08%
```

## 4. 方法 / 架构 / 构建

```text
1. 初始化策略池
2. LLM 生成/演化排序策略代码
3. 语法与可执行性检查
4. Wire-mask-guided greedy placement 作为 proxy evaluator
5. 并行评估候选策略
6. 以 proxy fitness 选 top-K 精英
7. 回到 LLM 进行下一代演化
8. 用最优策略运行完整 greedy/mixed-size 流程
```

核心不是直接搜索宏坐标，而是让 LLM 生成 `strategy(macro)` 这类排序策略。通过低不确定性的贪心探测器，输入顺序对最终 HPWL 的敏感性被放大，从而在无需完整 placement 迭代成本的情况下筛选策略。

## 5. 关键公式

- 贪心位置选择：$p_t=\arg\min_p \Delta HPWL(\pi_t,p,B)$，其中 $\pi_t$ 是当前宏，$B$ 是已放置宏边界。
- 总 HPWL：$HPWL(P)=\sum_{e\in E}(\max_{i\in e}x_i-\min_{i\in e}x_i+\max_{i\in e}y_i-\min_{i\in e}y_i)$。
- Wire mask：$W_m(i,j)=\sum_e HPWL_e(i,j)$，用于快速估计候选网格点增量成本。
- 策略 fitness：$fitness(\Pi)=\frac{1}{K}\sum_{i=1}^{K}HPWL(\Pi,seed_i)$，多种子平均以抑制噪声。
- 发现的动态策略可包含连接强度 $|N(m_i,m_j)|^\alpha$、物理距离因子 $\psi(m_i,m_j)$ 等代码级规则。

## 6. 训练 / 实验 / 评测协议

- 不需要训练或微调 LLM；使用 inference-time LLM 生成和演化策略。
- 主评测在 ISPD2005，公平对比 MaskPlace、ChiPFormer、WireMask-EA、EfficientPlace、EGPlace。
- proxy 使用多 seed 的 greedy placement，报告 mean ± std；完整实验的时间上限为 1000 分钟。
- 另在混合尺寸任务和 ChipBench/OpenROAD 流程上验证 HPWL、congestion、routed wirelength、power、WNS/TNS、NVP 和 area。
- 消融验证 LLM 生成策略相对手工策略的额外收益。

## 7. 创新点

1. 把宏布图优化从空间问题扩展到时间顺序问题，提出顺序是决定性维度。
2. 第一个 LLM 驱动、面向 macro placement sequencing 的演化框架。
3. 用低不确定贪心探测和 wire-mask proxy 降低昂贵反馈成本，使顺序搜索可扩展。

## 9. 与芯片流程的关系

OrderPlace 位于 floorplan/macro placement 与 standard-cell placement 之间的“顺序输入层”。它不替代 greedy placer，而是改变 placer 的宏进入顺序；这种前置优化会通过布局和布线传递到 final PPA。对于 analytical placer，论文还展示 OrderPlace 可作为排序前置与 DREAMPlace 组合。

## 10. 讨论与局限

- proxy 使用确定性贪心探测器，代理质量会影响排序信号是否可靠。
- 主要宏布图结果基于 ISPD2005，工业级复杂约束覆盖有限。
- LLM 演化策略的可解释性比手工规则强，但不同 LLM backend 的收敛速度和策略多样性仍需控制。
- 论文关注顺序维度，不替代完整 timing/power/routability 驱动的 placement 全流程。

## 12. 一分钟复述

宏放置不只是“放哪里”，先放哪些宏会形成不可逆的边界约束。OrderPlace 让 LLM 生成排序算法，用 wire-mask greedy placement 做便宜代理评估，再通过演化筛选优秀策略；最后把发现的最优顺序接入 greedy 或 analytical placer，在标准 benchmark 上显著降低 HPWL 和下游布线指标。
