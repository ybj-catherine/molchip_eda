> **PrefixRL: Optimization of Parallel Prefix Circuits using Deep Reinforcement Learning**

## 1. 一句话定位

**PrefixRL 把 32/64 位并行前缀加法器的拓扑优化建模为合法图上的多目标 Double-DQN：Agent 在不剪枝的指数级设计空间中增删节点，每个状态都经物理综合获得面积/延迟反馈，最终在同延迟下把 32 位和 64 位加法器面积最多降低 16.0% 与 30.2%。**

这句话有四个承重点：

1. **优化对象不是任意 RTL。** 论文针对可表示为 prefix-sum 的电路，主要实验是 32 位和 64 位并行前缀加法器；优先编码器、递增/递减器等只是可扩展方向。
2. **搜索空间不靠手写规则裁剪。** 状态是合法前缀图，动作是在候选位置增删节点，环境用 legalization 自动补齐必要父节点，避免生成非法电路。
3. **奖励来自 synthesis-in-the-loop。** 每次状态变化都生成门级网表，并在 4 个时序约束下运行 OpenPhySyn，奖励比较综合后的面积—延迟曲线，而不是只比较节点数、逻辑级数或扇出解析式。
4. **多目标靠多策略形成 Pareto 前沿。** 网络分别学习面积与延迟的 Q 值，再用权重标量化选动作；训练多个权重不同的 Agent，得到覆盖不同面积—延迟偏好的设计集合。

## 3. 输入 / 输出

这一节用 4 位前缀图说明状态、动作和输出；论文主结果使用同样机制扩展到 32 位与 64 位。

### 3.1 输入

前缀计算定义为 $y_i=x_i\circ x_{i-1}\circ\cdots\circ x_0$，其中运算符满足结合律。节点 $(i,j)$ 表示中间量 $z_{i:j}$。环境输入是一个合法前缀图、可增删节点集合和面积/延迟偏好权重。

```text
N = 4
initial graph = ripple-carry

mandatory input nodes:  (0,0) (1,1) (2,2) (3,3)
mandatory output nodes:       (1,0) (2,0) (3,0)
optional positions:           (2,1) (3,1) (3,2)

scalarization weight:
  w_area  = 0.70
  w_delay = 0.30
```

网络实际看到的是 $N\times N\times4$ 张量：四个通道分别表示节点是否存在、是否属于可直接删除的 `minlist`、节点逻辑级数和扇出，全部归一化到 0 到 1。

### 3.2 中间产物

假设 Agent 选择 `add (3,2)`。环境会检查该节点的上下父节点；若缺少下父节点，就自动补齐，保证图仍能计算所有输出前缀。

```text
state st: ripple-carry prefix graph
action at: add node (3,2)

legalize:
  upper parent = (3,3)
  lower parent = (2,2)
  both exist -> graph remains legal

synthesis at 4 timing targets:
  st   -> interpolated area-delay curve Ct
  st+1 -> interpolated area-delay curve Ct+1

reward = [area(Ct)-area(Ct+1), delay(Ct)-delay(Ct+1)]
```

每个状态先生成 NAND/NOR、OAI/AOI、XNOR、NOR、INV 组成的门级加法器，再由 OpenPhySyn 做门尺寸、复制、缓冲与引脚交换。四个采样点通过 PCHIP 插值得到曲线，权重 $w$ 决定从曲线上取哪个工作点比较。

### 3.3 输出

单个 Agent 输出与特定面积—延迟权重对应的合法前缀图；多个 Agent 合并后形成 Pareto 前沿。它不是一串抽象动作，而是可转换成门级网表的具体加法器结构。

```text
optimized prefix graph:
  nodes = {(0,0),(1,1),(2,2),(3,3),
           (1,0),(2,0),(3,0),(3,2)}

generated artifact:
  legal parallel-prefix adder netlist

reported QoR:
  cell area + critical-path delay after physical synthesis
```

输出不包含 RTL testbench、布局坐标或功耗报告。论文明确把功耗目标与非均匀输入/输出时序约束留作未来工作。

## 4. 方法与架构

这一节解释 PrefixRL 如何同时保证功能结构合法、接入昂贵综合器并让训练规模可承受。

### 4.1 整体 Pipeline

```text
        Ripple-carry 或 Sklansky 初始图
                       │
                       ▼
┌────────────────────────────────────────┐
│ N×N×4 状态张量                         │
│ 存在 / minlist / level / fanout        │
└────────────────────────────────────────┘
                       │
                       ▼
┌────────────────────────────────────────┐
│ ResNet Q-network                       │
│ 输出每个位置 add/delete 的面积与延迟 Q │
└────────────────────────────────────────┘
                       │ 标量化后选动作
                       ▼
               增删节点 + Legalize
                       │
                       ▼
         生成门级前缀加法器（Nangate45）
                       │ 4 个时序目标
                       ▼
   OpenPhySyn：size / clone / buffer / pin swap
                       │
                       ▼
        PCHIP 面积—延迟曲线 + 奖励向量
                       │
                       ▼
       Replay buffer + Scalarized Double-DQN
```

论文 Fig. 1 给出 Agent—环境闭环，Fig. 2 给出卷积 Q 网络，Fig. 3 给出四点综合与曲线插值的奖励计算。三者共同构成方法，不能只复现网络而省略综合反馈。

### 4.2 合法前缀图环境

所有输入节点 $(i,i)$、输出节点 $(i,0)$ 和节点 $(0,0)$ 必须存在。一个非输入节点 $(i,j)$ 要由上父节点与下父节点组合得到，父节点的位区间必须首尾衔接。`minlist` 记录不是其他节点下父节点的可删除节点。

添加动作先把节点放入 `minlist`，再更新受影响节点的依赖；删除动作只允许作用于 `minlist`，避免删完又被合法化过程原样补回。`Legalize` 从高位到低位扫描，发现缺少下父节点就补节点，因此每个可见状态都保持功能合法。

### 4.3 Scalarized Double-DQN

Agent 不把面积与延迟提前压成一个奖励，而是学习二分量 Q 向量 $[Q_{area},Q_{delay}]$。选动作时才用权重 $w$ 组合，这让网络保留“某动作改善面积但牺牲延迟”的方向信息。

每个训练 run 固定一个权重。论文用 15 组权重，范围为 0.10 到 0.99；将各 run 的输出合并并去除被支配点，就得到 Pareto 前沿。面积和延迟单位不可直接相加，所以实验还用 $c_{area}=0.001$ 与 $c_{delay}=10$ 做尺度校准。

### 4.4 Q 网络

输入先经过 5×5 卷积、批归一化和 Leaky-ReLU，再进入 32 个残差块，每块有 256 个通道；输出头生成 $N\times N\times4$ 张量，四个通道分别对应 add/delete 下的面积 Q 值与延迟 Q 值。非法动作的 Q 值被置为负无穷，保证不会被选择。

32 位和 64 位使用相同的 32 个残差块与 256 通道。64 位状态更大，论文没有继续扩模型容量，而是通过 14 块数据并行 GPU 和更小的每 GPU batch 处理显存压力。

### 4.5 综合在环与分布式系统

64 位 Sklansky 状态在 4 个时序约束下综合平均需 35.56 秒，而 RL 至少要 $10^5$ 级环境步。论文启动 192 个综合 worker 异步生成经验，并利用 DQN 的 off-policy 属性让学习与采样解耦；流水并行隐藏单次综合延迟，缓存则减少重复状态求值。

当探索率下降后，32 位缓存命中率约 50%，64 位约 10%。64 位 500,000 个环境步在并行系统上约训练 5 天；单线程估计约 44 天。这个系统工程是方法可运行的必要组成部分。

### 4.6 模块职责矩阵

| 模块 | 输入 | 输出 | 模型/工具 | 是否训练 |
|---|---|---|---|:---:|
| Prefix 环境 | 合法图 + 增删动作 | 下一合法图 | Legalize 算法 | 否 |
| Q-network | $N\times N\times4$ 状态 | 面积/延迟动作价值 | 32-block ResNet | 是 |
| 标量化决策 | Q 向量 + 权重 $w$ | 单个动作 | 加权 argmax | 否 |
| 网表生成 | 前缀图 | 门级加法器 | Nangate45 cells | 否 |
| 综合反馈 | 门级网表 + 4 个时序目标 | 面积—延迟采样点 | OpenPhySyn | 否 |
| 分布式采样 | 大量待评估状态 | replay experience | 192 synthesis workers | 否 |

## 5. 关键公式

这一节从前缀图合法性、搜索空间到多目标 Q 学习依次展开。

### 5.1 前缀计算

$$
y_i = x_i \circ x_{i-1} \circ \cdots \circ x_0
$$

- $x_i$：第 $i$ 个输入元素。
- $y_i$：从 $x_i$ 到 $x_0$ 的前缀结果。
- $\circ$：满足结合律的二元运算。

结合律允许把串行依赖改写成树状并行计算。加法器中可把 generate/propagate 合并看成这种前缀运算，从而用不同图结构交换面积与关键路径深度。

### 5.2 状态空间与动作空间

$$
|S| = O\left(2^{(N-1)(N-2)/2}\right), \qquad |A| = \frac{(N-1)(N-2)}{2}
$$

- $N$：前缀电路的输入位数。
- $S$：所有合法前缀图的状态集合。
- $A$：可选非输入/输出位置上的增删动作集合。

32 位时可选位置数为 465，64 位为 1,953。状态组合数随位宽平方指数增长，这解释了为什么穷举和顺序模拟退火很难直接使用昂贵物理综合反馈。

### 5.3 Q 值与更新

$$
Q^\pi(s_t,a_t) = \mathbb{E}\left[r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots\right]
$$

- $s_t$：时刻 $t$ 的前缀图。
- $a_t$：在该图上的增删动作。
- $r_t$：动作造成的面积/延迟改善。
- $\gamma$：折扣因子，实验设为 0.75。

Q 值把当前结构修改与后续可能继续获得的收益联系起来，避免只做一步贪心的面积或延迟下降。

### 5.4 二维奖励

$$
r_t = \left[A(s_t)-A(s_{t+1}),\;D(s_t)-D(s_{t+1})\right]
$$

- $A(s)$：状态 $s$ 综合后选定工作点的面积。
- $D(s)$：状态 $s$ 综合后选定工作点的延迟。
- $r_t$：面积改善和延迟改善组成的奖励向量。

若新图面积更小，对应第一分量为正；若延迟更短，第二分量为正。保留向量能让网络区分两个目标的贡献。

### 5.5 Scalarized Double-DQN 目标

$$
y_t = r_t + \gamma Q\left(s_{t+1},\operatorname*{arg\,max}_{a}\left[w^T Q(s_{t+1},a;\theta_t)\right];\theta_t'\right)
$$

- $y_t$：Double-DQN 的目标 Q 向量。
- $w$：面积与延迟的非负权重向量。
- $\theta_t$：本地网络参数，用于选动作。
- $\theta_t'$：目标网络参数，用于评价该动作。

本地网络选动作、目标网络估值，降低普通 DQN 的过估计。标量化只用于 `argmax`，训练目标仍保留面积和延迟两个分量。

### 5.6 Pareto 权重尺度

$$
\operatorname{score}_w(s) = w_{area}c_{area}A(s) + w_{delay}c_{delay}D(s)
$$

- $w_{area}$、$w_{delay}$：偏好权重，非负且和为 1。
- $c_{area}$：面积尺度常数，实验为 0.001。
- $c_{delay}$：延迟尺度常数，实验为 10。
- $A(s)$、$D(s)$：综合后的面积与延迟。

尺度常数不是物理定律，而是把量纲不同的两个目标拉到可比较范围，使不同权重覆盖已有基线前沿的宽度。

## 6. 训练与实验设置

这一节说明论文的数值是在什么库、什么综合器和多大训练系统上得到的。

### 6.1 是否需要训练

需要从头训练深度 Q 网络。每局从 ripple-carry 或 Sklansky 图随机开始，使用随训练退火到 0 的 epsilon-greedy 探索。经验回放缓冲区最多 400,000 条记录，目标网络每 60 个梯度步同步一次，Adam 学习率为 $4\times10^{-5}$，折扣因子为 0.75。

论文为 15 个面积—延迟权重分别训练 Agent。32 位使用 1 块数据并行 GPU、每 GPU batch 96；64 位使用 14 块 GPU、每 GPU batch 6。两种位宽的网络均为 32 个残差块、256 通道。

### 6.2 实验设置

训练使用 OpenPhySyn 和 Nangate45。每个前缀图生成交替 NAND/NOR、OAI/AOI、XNOR、NOR、INV 门组成的网表，在 4 个时序目标下运行门尺寸、门复制、插缓冲和 pin swapping，再以 PCHIP 插值面积—延迟曲线。

最终比较在 40 个延迟目标上综合各方法产生的加法器并取 Pareto 前沿。32 位基线包括 Sklansky、Kogge-Stone、Brent-Kung、模拟退火和剪枝搜索；64 位还比较机器学习驱动的 cross-layer optimization 产生的 1,100 个加法器。

工业迁移实验选取 7 个 Pareto 最优 PrefixRL 加法器，在商业 8 nm 单元库和物理综合工具下用相同 12 个延迟目标重综合，与三类规则加法器及商业工具自带加法器比较。

### 6.3 开源综合主结果

| 位宽 | PrefixRL 最大面积节省 | 对应延迟目标 | 训练环境步 | 代表性基线 |
|---:|---:|---:|---:|---|
| 32 位 | **16.0%** | 0.293 ns | 约 250,000 | SA、PS、Sklansky、Kogge-Stone、Brent-Kung |
| 64 位 | **30.2%** | 0.347 ns | 500,000 | CL 1,100 个设计与规则结构 |

论文 Fig. 4 的关键不是只挑一个最好点，而是 PrefixRL 前沿在 OpenPhySyn/Nangate45 下 Pareto 支配已有方法。32 位大部分宽松时序目标只节省约 2 到 8 个百分点；到前沿拐点和紧时序目标时增益更明显。64 位拐点区域通常节省 12 到 20 个百分点，最大值为 30.2%。

### 6.4 训练系统扩展性

| 统计项 | 16 位 | 32 位 | 64 位 |
|---|---:|---:|---:|
| 动作数 $|A|$ | 105 | 465 | 1,953 |
| 单状态综合时间 | 11.39 s | 16.85 s | 35.56 s |
| 训练迭代时间 | 0.45 s | 1.61 s | 3.15 s |
| 残差块数 | 16 | 32 | 32 |
| 每 GPU batch | 96 | 96 | 6 |
| 数据并行 GPU | 1 | 1 | 14 |

这里的综合时间是 Sklansky 加法器在 4 个时序约束下的评价。64 位并行训练约 5 天；论文估算同样工作单线程约 44 天。结果证明工程并行化有效，也暴露了 synthesis-in-the-loop 的高成本。

### 6.5 工业库迁移与消融

在商业 8 nm 工具中，PrefixRL 设计除最低延迟目标外，整体优于 Kogge-Stone、Brent-Kung，并能达到比商业工具加法器和 Sklansky 更低的面积/延迟。这些 Agent 只在开放 45 nm 库上训练，因此实验说明拓扑具有一定跨库迁移性，但不能证明在所有工艺角和布线后条件下都占优。

只用解析面积/延迟模型训练时，Analytical-PrefixRL 在解析指标上比模拟退火最低延迟点面积低 11.7%；然而送入真实综合后，其结构反而不如 PS 和 Sklansky 易于优化。Fig. 6 由此证明：解析代理的 Pareto 最优不等于综合后最优，综合在环不是可随意删除的昂贵装饰。

## 7. 创新点

### 创新点 1：合法图上的无启发式拓扑探索

已有剪枝搜索依赖人工规则缩小空间，可能提前排除不规则但高质量的拓扑。PrefixRL 允许所有候选节点位置参与增删，仅用数学合法性约束环境，搜索策略从综合反馈中学习。

### 创新点 2：把真实物理综合放进 RL 奖励环

节点数、级数、最大扇出等解析量不能充分预测库映射后的面积与延迟，因为门负载、缓冲、复制和布线效应会改变结果。PrefixRL 直接运行 OpenPhySyn，让 Agent 学的是工具实际能实现好的结构。

### 创新点 3：多目标 Q 向量而非过早合并奖励

网络分别预测面积与延迟动作价值，只在决策时按偏好权重组合。多个权重 Agent 共同覆盖 Pareto 前沿，避免只给一个无法适应不同产品约束的“最优加法器”。

### 创新点 4：异步综合、缓存与 off-policy 并行训练

论文没有回避每步几十秒的综合瓶颈，而是用 192 个综合 worker、流水并行、状态缓存和 DQN 的 off-policy 性质把训练吞吐做起来。这套系统方案对其他“EDA 工具在环”的 RL 任务同样有参考价值。

## 9. 与芯片流程的关系

### 9.1 在全流程中的位置

PrefixRL 位于微架构确定“这里需要一个 N 位加法器”之后、该结构被集成进完整数据通路之前。它接手位宽和均匀时序约束，输出一张功能合法的前缀图和门级实现，交给更完整的逻辑综合、物理实现与 STA 流程继续处理。

这类优化的价值很高：加法器处在 CPU、GPU 和 AI 加速器的关键数据通路上，单个结构的面积/延迟改善可能影响整条流水线。但论文没有测量系统频率、能耗或应用性能，因此不能把 30.2% 的局部面积节省直接等同于整芯片 30.2% 改善。

### 9.2 “综合后 Pareto 最优”和“芯片内最优”之间隔着什么

首先，论文使用均匀输入到达与输出要求，真实数据通路可能每一位时序预算不同。其次，实验不把功耗作为第三目标，也未做完整 placement、routing、寄生提取和 signoff。最后，单独综合加法器时的最优结构在被周围寄存器、布线拥塞和电源约束包围后可能改变排序。

### 9.3 与资料包内相关工作的关系

- [CircuitEvo](../CircuitEvo/论文深度讲解.md) 同样搜索电路结构，但任务表示、搜索算法与评价闭环不同。
- [AutoPPA](../AutoPPA/论文深度讲解.md) 面向更一般的 PPA 优化；PrefixRL 是结构受限、反馈更具体的案例。
- [RTL-Sequencer](../RTL-Sequencer/论文深度讲解.md) 优化逻辑综合流程序列，而 PrefixRL 直接改变待综合电路拓扑。
- [GraphPlacement-RL](../GraphPlacement-RL/论文深度讲解.md) 用 RL 做宏布局；两篇共同说明 EDA 的昂贵工具可以充当环境，但状态、动作和真实物理约束必须针对任务定制。

## 10. 讨论与局限

### 10.1 论文自述的局限

功耗没有纳入目标，因为功耗仿真的计算开销过高。环境假设均匀输入到达和输出离开时间，尚未处理真实设计中的非均匀位级约束。64 位已需要 14 块 GPU 和 192 个综合 worker；向更宽位数或更一般数据通路扩展时，状态和动作空间继续快速增长。

### 10.2 代码与复现层面的问题

论文说明 OpenPhySyn 与 Nangate45 使训练流程原则上可复现，但没有给出 PrefixRL 的完整独立代码仓库、训练配置和全部生成网表。原始 PDF 带有 IEEE Xplore 的授权下载标记，因此本整理不把 PDF 移入公开候选目录，只保留 DOI/arXiv 链接和基于原文核对的讲解。

### 10.3 本资料包的批判性分析

第一，跨 45 nm 开放库到商业 8 nm 的迁移实验很有价值，但只选 7 个 Pareto 点，且未公开商业工具和库，外部无法完整复核。第二，多个标量化权重适合凸形前沿，非凸 Pareto 区域可能覆盖不足。第三，功能正确性由图构造保证，但从前缀图到实际门级网表的生成器仍应配形式等价或随机仿真，论文没有把这一层验证写成评测指标。第四，综合在环的优势明确，但成本使它更像离线 IP 搜索，而不是日常每次 RTL 编译都在线运行的轻量优化器。

## 12. 一分钟复述版

1. PrefixRL 用深度强化学习设计并行前缀加法器，不是生成通用 RTL。
2. 状态是 $N\times N\times4$ 的合法前缀图，动作是在候选位置增删节点。
3. Legalize 自动补齐父节点，所以搜索过程中始终保持 prefix-sum 功能结构合法。
4. ResNet 分别输出面积和延迟 Q 值，按不同权重选动作；多个 Agent 合成 Pareto 前沿。
5. 每个状态都生成门级网表，并在 4 个时序目标下运行 OpenPhySyn 获取真实综合反馈。
6. 32 位和 64 位在同延迟下最大面积节省分别为 16.0% 和 30.2%。
7. 只用解析指标训练的结构综合后会变差，证明 synthesis-in-the-loop 是关键。
8. 64 位训练需 500,000 步、14 块 GPU、192 个综合 worker，约 5 天。
9. 局限是未优化功耗、只支持均匀时序约束、核心训练代码未完整开源。
10. 最准确的定位是：用昂贵 EDA 反馈训练一个专用拓扑搜索器，离线发现传统规则没覆盖的加法器结构。
