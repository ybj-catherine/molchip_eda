## 1. 一句话定位

**该工作提出 MLLMA，用多模态 LLM 同时预测 routing congestion 并生成可解释的 Design Suggestion Deck；MLLM-guided genetic prompting 自动生成布局特征，再用可解释偏好学习把视觉、表格和文本输入转成工程师可执行的设计建议。**

## 3. 输入 / 输出

### 3.1 输入

- 几何图像特征：Macro Region、RUDY、RUDY pin。
- 表格特征和配置文件、日志中的文本特征。
- CircuitNet benchmark 的 congestion 标签。

```text
mllma_input = {
  images: ["macro_region.png","rudy.png","rudy_pin.png"],
  tabular_features: ["macro_density","pin_density","net_count"],
  text_features: ["config","log_summary"],
  task: "congestion_prediction_and_suggestion"
}
```

### 3.2 输出

- 多模态 congestion 预测分数。
- Design Suggestion Deck：按重要性排序的布局特征和针对性优化建议。
- 可解释偏好，说明视觉、表格、文本特征如何影响 congestion。

```text
mllma_output = {
  congestion_prediction: 0.82,
  top_feature: "rudy_pin_gradient_variability",
  suggestion: "reduce macro channel crowding and spread pin clusters"
}
```

## 4. 方法 / 架构 / 构建

```text
Layout images + tabular features + text
          |
Stage 1: MLLM-guided genetic prompting
          |
Feature generation, mutation/crossover, deduplication
          |
Random Forest importance + cross validation
          |
Stage 2: Interpretable preference learning
          |
Design Suggestion Deck
```

第一阶段用 MLLM agent 生成和提取数值特征，并用 Genetic Instruct 风格的 mutation/crossover 扩展特征池。第二阶段把重要特征翻译成可解释规则，让模型不仅能预测，还能解释哪些 layout pattern 导致 congestion。

## 5. 关键公式

- Congestion 预测：$\hat y=f_{\theta}(I_{image},x_{tab},x_{text})$。
- 特征重要性：$Importance_j=\sum_{t\in trees}\Delta impurity_{t,j}$。
- 偏好模型：$P(prefer\ s_i \succ s_j)=\sigma(u(s_i)-u(s_j))$。
- Design suggestion 排序：按特征重要性、预测增益和工程师可解释性综合排名。

## 6. 训练 / 实验 / 评测协议

- 不微调 MLLM，使用 guided genetic prompting 生成特征。
- 在 CircuitNet 上比较 congestion 预测准确性和可解释性。
- 设计建议 guidance case study 和 qualitative analysis 验证建议符合真实设计原则。

## 7. 创新点

1. 把物理设计 assistant 从纯预测升级为可解释预测 + 可执行设计建议。
2. 用 MLLM-guided genetic prompting 自动做特征工程。
3. 用可解释偏好学习统一视觉、表格和文本 tradeoff，并输出 Design Suggestion Deck。

## 9. 与芯片流程的关系

MLLMA 聚焦 physical design 的 congestion 分析和设计建议，横跨 floorplan、placement 与 routing。它不是替代 P&R 工具，而是在工程师修改布局时提供可解释的区域级反馈，帮助减少 routing congestion 和后续 DRC/timing 压力。

## 10. 讨论与局限

- 任务主要是 congestion 预测和 suggestion，未形成完整 placement/routing 自动修复闭环。
- 实验以 CircuitNet 为主，真实工业布局和更多工艺节点需进一步验证。
- MLLM 生成特征和规则受 prompt 与模型能力影响，特征语义一致性需要控制。
- 可解释建议的有效性主要依赖 case study 和 qualitative analysis，缺少统一量化修复收益。

## 12. 一分钟复述

传统 congestion 模型往往只给一个热图或分数，工程师不知道该怎么改。MLLMA 让多模态 LLM 自动生成布局特征，经过遗传 prompting 扩展和随机森林重要性筛选，再把关键特征翻译成设计建议卡片。结果既预测 congestion，也给出“哪里堵、为什么堵、怎么改”的工程解释。
