# VeoPlace 论文深度讲解

> **See it to Place it: Evolving Macro Placements with Vision-Language Models**
> Ikechukwu Uchendu, Swati Goel, Karly Hou, Ebrahim Songhori, Kuang-Huei Lee, Joe Wenjie Jiang, Vijay Janapa Reddi, Vincent Zhuang；arXiv:2603.28733
> 原文：[2603.28733_See-it-to-Place-it.pdf](./2603.28733_See-it-to-Place-it.pdf) · [2603.28733_See-it-to-Place-it.txt](./2603.28733_See-it-to-Place-it.txt)

## 1. 一句话定位

**VeoPlace 用不微调的 VLM 做高层空间推理，把 base placer 的动作约束到有前景的芯片子区域，再用进化搜索迭代优化这些视觉 proposal；在 ChiPFormer 和 DREAMPlace 两类 base placer 上都显著提升 macro placement HPWL。**

## 3. 输入 / 输出

### 3.1 输入

- 未见芯片的 macro 集合、网表、可布局 canvas。
- 当前 placement 图像或空间候选区域。
- base placer：ChiPFormer 或 DREAMPlace。
- 在线预算 $B$ 次 placement attempt。

```text
veoplace_input = {
  benchmark: "superblue5",
  base_placer: "DREAMPlace",
  rollouts: 2000,
  vlm: "Gemini",
  mode: "soft_anchor_constraints"
}
```

### 3.2 输出

- VLM 建议的宏/区域约束或 action mask。
- 进化搜索后的高质量 placement。
- HPWL 曲线和相对 base placer 的改善比例。

```text
veoplace_output = {
  hpwl_best: "5.2e7",
  improvement_vs_base: "4.3%",
  benchmarks_improved: "8/8"
}
```

## 4. 方法 / 架构 / 构建

```text
Unseen chip + base placer
          |
VLM proposes subregions / anchors
          |
Low-level placer executes constrained placement
          |
Evaluate resulting HPWL
          |
Evolutionary population update
          |
Return best placement
```

VeoPlace 的高层 VLM 只看布局图像和性能指标，从历史 placement 中提取空间模式；低层 placer 保持原有优化能力。对 learning-based policy，VLM 通过 action mask 禁止无前景区域；对 analytical placer，VLM 通过 soft anchor constraints 限制宏的区域偏好。

## 5. 关键公式

- 在线优化目标：$\arg\max_{\pi} E[HPWL(P_{\pi}(x))]$，其中 $\pi$ 是 VLM 指导策略，$x$ 是未见芯片。
- Action mask：$a_t\in \mathcal{A}_{VLM}(s_t)\subseteq \mathcal{A}$，VLM 根据视觉状态限制低层 placer 动作集。
- Soft anchor cost：$L_{anchor}=\sum_i w_i \cdot d(m_i,R_i)$，其中 $R_i$ 是 VLM 给宏 $m_i$ 的建议区域。
- 进化选择以最终 HPWL 为 fitness，population 保存 proposal 区域和 anchor 配置。

## 6. 训练 / 实验 / 评测协议

- VLM 不微调，使用公开 Gemini 模型。
- 在 ISPD2005、ICCAD2004、Ariane 上评测 ChiPFormer，报告 9/10 benchmark 优于 ChiPFormer，峰值 HPWL 降低超过 32%。
- 在 ICCAD2015 Superblue 上评测 DREAMPlace，报告 8/8 benchmark 改善，最高 4.3%。
- 多次 rollouts，报告 mean ± standard error。

## 7. 创新点

1. 首个把 VLM 作为 macro placement 高层空间推理器，并无需微调。
2. 统一支持 action masking 和 soft anchor constraints 两类 base placer。
3. 用进化搜索持续优化视觉 proposal，突破单次 VLM 建议的局部性。

## 9. 与芯片流程的关系

VeoPlace 位于 macro/standard-cell placement 阶段，是一个可插拔的 high-level guidance 层。它不改变 DREAMPlace 或 ChiPFormer 的核心优化器，而是限制其搜索空间，使有限在线预算更快用于有前景区域。对后续 routing、timing 和 PPA 的直接影响需要通过下游流程继续验证。

## 10. 讨论与局限

- 主要指标是 HPWL，未系统报告 post-route timing、power 和 congestion。
- VLM 建议依赖图像质量和 prompt 设计，长 horizon 和复杂约束仍有风险。
- 对未见 chip 的泛化来自少样本视觉上下文，不能保证所有 floorplan 类型都稳定。
- 软约束与 action mask 的强度需要调优，否则可能过度限制 base placer。

## 12. 一分钟复述

人类设计师做宏布图时靠视觉判断区域好坏。VeoPlace 让 VLM 看 placement 图像和历史 HPWL，给出宏应该去的区域；底层 placer 在这个约束下执行布局，进化算法再筛选更优 proposal。这样既保留专用 placer 的优化能力，又加入跨芯片的空间先验。
