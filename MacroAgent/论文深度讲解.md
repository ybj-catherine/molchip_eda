# MacroAgent 论文深度讲解

> **MacroAgent: Regularity-Aware Macro Legalization with LLM-Agent-Designed Contour Algorithms**
> Jiaxi Jiang, Xufeng Yao, Yuxuan Zhao, Yuntao Lu, Peiyu Liao, Zuodong Zhang, Yibo Lin, Bei Yu
> arXiv:2608.24946
> 原文：[2608.24946_MacroAgent.pdf](./2608.24946_MacroAgent.pdf) · [2608.24946_MacroAgent.txt](./2608.24946_MacroAgent.txt)

## 1. 一句话定位

**MacroAgent 把宏合法化分解为聚类、轮廓生成、模板匹配、簇间精化四阶段，并让 LLM agent 设计 regularity-aware contour 算法；在 TILOS 和 Chipyard 上改善 2–8 倍布局规整性，同时降低 3%–5% routed wirelength。**

这句话里的三个承重点：

1. **规整性进入 legalization** — 传统合法化只最小化 displacement，不关注宏间通道和 deadspace。
2. **LLM 搜索 contour 算法** — 搜索对象是 `generate_contour(...)` 代码，而不是单个坐标或参数。
3. **多候选鲁棒性** — 每个 cluster 生成多个 contour/template 候选，再用 assignment 选择最小 displacement 解。

## 4. 方法与架构

### 4.1 整体 Pipeline

```text
Overlapped macro placement
          │
          ▼
Size-aware distance-based clustering
          │
          ▼
LLM agent designs contour algorithms
          │
          ▼
Contour generation
          │
          ▼
Template generation + Hungarian matching
          │
          ▼
Inter-cluster refinement
          │
          ▼
Legal and regular macro placement
```

### 4.2 核心模块逐个详解

- **Clustering**：按尺寸分类和 KD-tree 空间近邻聚簇，自适应距离阈值。
- **Contour Generation**：LLM 生成封闭 rectilinear contour，在 regularity 和 displacement 之间形成算法级 trade-off。
- **Template Matching**：在 contour 内生成均匀 grid，用 Hungarian algorithm 最小化宏到槽的位移。
- **Inter-cluster Refinement**：用 constraint graph 解决簇间 overlap，同时尽量保持簇内相对位置。

### 4.3 模块职责矩阵

| 模块 | 输入 | 输出 | 工具/模型 | 是否需训练 |
|---|---|---|---|---|
| Clustering | macro positions | clusters | Python + KD-tree | 否 |
| Contour design | prompt + previous code | contour code | LLM agent | 否 |
| Template matching | contour, macros | macro slots | Hungarian algorithm | 否 |
| Refinement | clusters | legal placement | constraint graph | 否 |

## 5. 关键公式

### 5.1 规整性指数

$$
R=1-\frac{C-C_{\min}}{C_{\max}-C_{\min}}
$$

- $R$：规整性指数
- $C$：当前通道数
- $C_{\min}$：理论最小通道数
- $C_{\max}$：最差可接受通道数

### 5.2 Displacement

$$
D=\sum_i \left(|x_i'-x_i|+|y_i'-y_i|\right)
$$

- $D$：总 Manhattan displacement
- $(x_i,y_i)$：初始坐标
- $(x_i',y_i')$：合法化坐标

### 5.3 Template cell

$$
w_{\text{cell}}=\max_i w_i+c,\qquad h_{\text{cell}}=\max_i h_i+c
$$

- $w_i,h_i$：宏宽高
- $c$：最小 channel spacing

## 6. 训练与实验设置

### 6.1 是否需要训练

不训练。LLM agent 使用生成、执行、评价和可视化反馈。搜索过程依赖 prompt 中的 prior ideas、前序代码和 metric 结果，不更新模型权重。

### 6.2 实验设置

- TILOS 用于 contour 算法发现，Chipyard 用于泛化测试。
- 学术流程：DREAMPlace + HeLEM-GR。
- 工业流程：Cadence Innovus place-and-route。
- 指标：regularity、displacement、runtime、routed wirelength、congestion、WNS/TNS、power。

### 6.3 关键实验结果

| 场景 | 结果 |
|---|---|
| TILOS vs DREAMPlace 2.0 | wirelength 降低约 5% |
| Chipyard vs baseline | wirelength 降低 3%–5% |
| Innovus end-to-end vs DREAMPlace | routed wirelength 降低 2.9%，TNS 改善 68.3% |

LLM 发现的多轮廓算法提高了鲁棒性，避免单一矩形轮廓在复杂 cluster 上产生过大 displacement。

## 7. 创新点

1. 首次在最终 macro legalization 中显式优化宏间规整性。
2. 让 LLM 直接设计 contour generation 算法，形成多种几何 trade-off。
3. 用 template + Hungarian matching 把规整性和位移优化解耦，便于候选组合。

## 9. 与芯片流程的关系

### 9.1 在全流程中的位置

MacroAgent 位于 mixed-size global placement 之后，决定宏的最终合法位置和通道结构，是标准单元 placement 和 routing 的前置条件。

### 9.2 从“legalization 改善”到“能做成芯片”之间还缺什么

论文报告 post-route wirelength、congestion 和 timing，但未覆盖完整 DRC/LVS、IR drop、多 corner 和制造验证。

## 10. 讨论与局限

### 10.1 论文自述的局限

规整性主要作用在 intra-cluster；inter-cluster fallback 可能牺牲部分规整性。LLM 目前只设计 contour 算法，未来应扩展到 clustering 和 inter-cluster。

### 10.2 代码/复现层面的问题

没有公开代码，LLM prompt 细节和完整算法库不完整。论文展示 prompt 片段和部分 contour 函数，但完整遗传流程、可视化和模板生成实现无法直接复现。

### 10.3 本资料包的批判性分析

规整性指数的定义依赖通道阈值，实际收益与下游 router 密切相关。多候选机制带来鲁棒性，但也会增加 runtime 和候选筛选复杂度。

## 12. 一分钟复述版

传统宏合法化只求把重叠宏推开并最小位移，容易留下不规则通道。MacroAgent 先聚类，再让 LLM 自动发现轮廓算法；每种轮廓生成模板网格，用 Hungarian 匹配最小化位移；最后解决簇间 overlap。多轮廓策略比单一矩形轮廓更鲁棒，能同时改善规整性、wirelength 和 TNS。
