# MacroAgent 论文深度讲解

> **MacroAgent: Regularity-Aware Macro Legalization with LLM-Agent-Designed Contour Algorithms**
> Jiaxi Jiang, Xufeng Yao, Yuxuan Zhao, Yuntao Lu, Peiyu Liao, Zuodong Zhang, Yibo Lin, Bei Yu；arXiv:2608.24946
> 原文：[2608.24946_MacroAgent.pdf](./2608.24946_MacroAgent.pdf) · [2608.24946_MacroAgent.txt](./2608.24946_MacroAgent.txt)

## 1. 一句话定位

**MacroAgent 把宏合法化重构为聚类、轮廓生成、模板匹配、簇间精化四阶段，并用 LLM agent 发现多种 regularity-aware contour 算法；在 TILOS 和 Chipyard 上显著提升布局规整性，同时降低 routed wirelength。**

## 3. 输入 / 输出

### 3.1 输入

- 初始存在重叠或非规整的宏 placement。
- 宏尺寸、位置、cluster 信息，以及用于 LLM 发现的 testcases。
- 工程设定：轮廓算法种群、prompt、指标定义和下游 P&R 流程。

```text
legalization_input = {
  macros: [{"id":"m0","w":20,"h":10,"x":100,"y":120}, ...],
  overlaps: true,
  target_regularity: "channel_based",
  downstream: "DREAMPlace + HeLEM-GR"
}
```

### 3.2 输出

- 无重叠且具备工程级规整性的宏合法布局。
- 每个 cluster 的 contour、template 和 macro-to-slot assignment。
- 最多 20 个按 displacement 排序的候选合法化结果。
- routed wirelength、congestion、WNS、TNS、power 和 legalization runtime。

```text
legalization_result = {
  routed_wirelength_improvement: "3%-5%",
  regularity_improvement: "2x-8x",
  robustness: "all_legalized",
  end_to_end_vs_dreamplace: {routed_wirelength: -2.9%, TNS: -68.3%}
}
```

## 4. 方法 / 架构 / 构建

```text
Overlapped Macro Placement
          |
1. Clustering (size-aware distance-based)
          |
2. LLM Agent discovers contour algorithms
          |
3. Contour generation -> regularity-aware polygon
          |
4. Template generation and Hungarian macro matching
          |
5. Inter-cluster refinement
          |
Legal and regular macro placement
```

LLM agent 的搜索对象是 `generate_contour(corners, centers, ...)` 这类可执行 Python 函数。每个候选轮廓用 regularity index 和 displacement 评价；保留在不同 testcase 上至少一个指标更好的算法，形成多样轮廓库。

## 5. 关键公式

- 规整性指数：$R=1-\frac{C-C_{min}}{C_{max}-C_{min}}$ 或等价通道数归一化，越接近 1 越规整。
- 位移目标：$\sum_i(|x_i'-x_i|+|y_i'-y_i|)$。
- 模板网格 cell 尺寸：$w_{cell}=\max w_i+c$，$h_{cell}=\max h_i+c$，其中 $c$ 是 channel spacing。
- 宏到网格槽的匹配使用线性 assignment/Hungarian algorithm，最小化总位移。
- 簇间精化采用 constraint graph，最小化 $\|x-x'\|_1+\|y-y'\|_1$，同时保持簇内相对位置以保护规整性。

## 6. 训练 / 实验 / 评测协议

- LLM 不训练，使用 agent 生成、执行、评价和可视化反馈。
- 在 TILOS 上用简单 case 发现 contour 算法，在 Chipyard 上测试泛化。
- 学术流程为 DREAMPlace + HeLEM-GR，工业流程为 Cadence Innovus place-and-route。
- 指标包括 regularity、displacement、legalization runtime、routed wirelength、congestion、WNS、TNS、power。

## 7. 创新点

1. 首次在最终 macro legalization 阶段显式优化宏间规整性。
2. 用 LLM agent 发现多种轮廓算法，形成算法级 trade-off，而不是只调参数。
3. 四阶段框架把轮廓生成与模板匹配、簇间精化解耦，鲁棒性优于单一固定轮廓。

## 9. 与芯片流程的关系

MacroAgent 是 mixed-size global placement 之后的宏合法化插件，位于 floorplan/macro placement 的收尾步骤。它决定宏最终位置和通道结构，从而影响 standard-cell 可布空间、routing detour 和最终 PPA。该模块与 DREAMPlace 或 Innovus 均可集成。

## 10. 讨论与局限

- 规整性主要在 intra-cluster 阶段保持，inter-cluster fallback 可能部分牺牲规整性。
- LLM 设计目前局限于 contour generation，尚未扩展到 clustering 和 inter-cluster 算法设计。
- 对下游 PPA 的评估依赖具体 P&R flow，跨工艺或跨工具泛化仍需额外验证。
- 轮廓多样性会带来候选选择和 runtime 成本。

## 12. 一分钟复述

传统宏合法化只求不重叠和最小位移，常常忽略宏之间的通道规整性。MacroAgent 先按尺寸和空间聚类，再让 LLM agent 自动发现轮廓算法，用模板网格和 Hungarian 匹配把宏贴到规整槽位，最后做簇间精化。结果比单一矩形轮廓更鲁棒，能同时改善规整性、routed wirelength 和 timing。
